# Release Notes v0.4.1

Released: 2026-11-25

## Highlights

- **A step whose checks fail stops the run.** `run` exits non-zero, and a
  phase run stops at that step instead of reporting the phase done.

## Fixed

- A step whose actions were done but whose checks failed was recorded as
  `failed`, yet `run` returned success. A phase run went on to the next
  step and, at the end, said the phase was done. `Runner.Run` now returns
  `ErrChecksFailed`, and a phase run reports:

  ```
  Phase 8 (…) stopped at step 8.10 "…": its actions are done, but its checks failed (http-www…).
  Fix what they found, then check again: bin/infra runbook verify 8.10 --record
  Resume the phase: bin/infra runbook run 8
  ```

## Documentation

- The getting-started guide says what a run does when a step's checks
  fail.

## Upgrading

A program that calls `Runner.Run` and treated a nil error as "verified"
now gets `ErrChecksFailed` when checks fail; test for it with
`errors.Is`. Nothing else changes.
