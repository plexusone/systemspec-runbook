# Release Notes v0.2.0

Released: 2026-11-22

## Highlights

HTML pages are built from the runbook with [templ](https://templ.guide)
components rather than converted from the Markdown page, so the HTML has
a layout of its own while the Markdown page stays as it is.

## Added

- **Copy buttons.** Every code block on the HTML page has a button that
  copies its command for pasting into a terminal, with the clipboard API,
  or a selection where a page opened from a file cannot use it. `Script`
  is the script, for a host that places the fragment in its own page.

## Changed

- **The HTML page** uses the window's full width. The phase summary is a
  table; each step is a section with its owner's badge (operator, agent
  or both), its dependencies linked, its actions numbered with their own
  owners' badges and their commands escaped in code blocks, then the
  credentials it creates, when it is done and its checks.
- **Anchors** are the Markdown page's, so `[[step:1.2]]` links and the
  links in a runbook's text land on the same step on both pages.
- **Text fields** are still Markdown, converted with goldmark without
  passing raw HTML through, and placeholders such as `<value>` are shown.
- **`Style`** is the full-width sheet with the step and badge styles, for
  a host that places the fragment in its own page.

## Dependencies

- Requires `github.com/a-h/templ` v0.3.1118. `go generate ./runbookspec`
  regenerates the components with that version.

## Upgrading

No code change is needed: `HTML`, `HTMLOptions` and `Style` keep their
names. A host that places the fragment adds `Script` after it for the
copy buttons. A host that styled the old page's elements should check its rules
against the new structure.
